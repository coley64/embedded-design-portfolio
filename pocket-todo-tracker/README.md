# Pocket To-Do Tracker (WIP)

- Design Problem: I want to create a portable, handheld embedded device that can track my daily list of tasks. I want it to be lightweight, easy to carry around, low-power, easy-to-read, and easy-to-update.

- Tech Stack:
  - SSD1306 OLED Display to show tasks, updated via I2C
  - Buttons to control which tasks are 'marked as completed'
  - Portable power supply, maybe triple-A battery pack? Need to check voltage and current requirements
